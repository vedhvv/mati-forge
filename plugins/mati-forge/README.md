# Mati Forge plugin

Quietly notes the moments you correct Claude in Cowork, and subagents that fail, as short summaries on your computer. Claude drafts a one-line rule from each correction; rules start provisional, are used from the next task on, and you can keep, drop or reword them. At the start of a task Claude is briefed with the most relevant rules, and a weekly report shows whether mistakes stop repeating.

This plugin holds the hooks and the skill. It needs the Mati Forge desktop extension, which stores everything locally in `~/MatiForge` and makes no network calls. Install steps, privacy details and source: https://github.com/vedhvv/mati-forge
